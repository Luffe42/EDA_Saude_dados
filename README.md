# EDA_Saude_dados
# Análise Exploratória de Dados - Risco à Saúde

Projeto desenvolvido durante o curso de Análise de Dados com Python - SENAI.

## Objetivo

Realizar uma análise exploratória para identificar padrões
e associações entre características demográficas,
comportamentais e a classificação de risco à saúde.

## Tecnologias

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Etapas

- Carregamento dos dados
- Inspeção e tratamento da qualidade
- Análise univariada
- Análise bivariada
- Análise de correlação
- Visualização dos dados
- Interpretação dos resultados
